# 斗棋竞技场（军棋白板版）

暗黑魔幻 + 东方符箓风格的军棋对战游戏。白板棋子 + 等级分配系统，后续可扩展为《斗棋竞技场》的自定义棋子、锻体、符文系统。

## 项目结构

```
/workspace
├── engine/    # 纯逻辑游戏引擎（TypeScript，54 测试通过）
├── server/    # Express + Socket.IO 服务端
├── client/    # React + Vite 前端
└── README.md
```

## 核心特性

### 游戏引擎
- 12×5 棋盘，60 个停靠点（公路/铁路/行营/大本营）
- 每方 25 枚棋子：军旗×1、地雷×3、炸弹×2、工兵×3、白板×16
- 白板棋子等级分配（100 等级点，单枚 0-9）
- 碰撞规则：等级高吃低、同级同归、炸弹同归、工兵吃雷、军旗被碰即输
- 铁路直线阻挡（含工兵）、工兵铁路拐弯
- 棋子改名（≤3字，仅己方可见）

### 服务端
- BCrypt 密码哈希 + JWT 认证
- 房间系统（创建/加入/准备/断线重连）
- 服务端权威裁定
- 暗棋信息隔离（敌方棋子无名字/等级）
- 气运值排行榜

### 前端
- 暗黑魔幻 + 东方符箓主题
- Canvas 棋盘渲染（石质底纹、暗金铁路、行营蓝光、大本营暗红）
- 布阵阶段：自动布阵、等级点分配
- 行棋阶段：点击选子、可移动点高亮
- 暗棋显示：敌方统一石质背面

## 快速开始

### 1. 启动引擎测试

```bash
cd engine
npm install
npx vitest run
```

### 2. 启动服务端

```bash
cd server
npm install
npm run build
node dist/index.js
# 服务运行在 http://localhost:3001
```

### 3. 启动前端

```bash
cd client
npm install
npm run dev
# 前端运行在 http://localhost:5173
```

### 4. 开始对局

1. 打开两个浏览器窗口，分别注册两个账号
2. 一方创建房间，另一方用房间码加入
3. 双方点击「准备」进入布阵阶段
4. 点击「自动布阵」或手动放置棋子，分配等级点
5. 双方「确认布阵」后进入对局
6. 轮流走子，吃掉对方军旗获胜
